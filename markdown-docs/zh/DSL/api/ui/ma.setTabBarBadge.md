## ma.setTabBarBadge(Object object)

> 为 tabBar 某一项的右上角添加文本（最低版本： 24.12.0）

### 参数

#### Object object

| 属性       | 类型       | 默认值 | 必填 | 说明                       |
|:---------|:---------|:----|:---|:-------------------------|
| index    | Number   |     | 是  | tabBar 的哪一项，从左边算起，从0开始   |
| text     | String   |     | 是  | 显示的文本，超过 4 个字符则显示成...    |
| success  | Function |     | 否  | 接口调用成功的回调函数              |
| fail     | Function |     | 否  | 接口调用失败的回调函数              |
| complete | Function |     | 否  | 接口调用结束的回调函数（调用成功、失败都会执行） |

### 示例代码

```js
ma.setTabBarBadge({
  index: 0,
  text: '111'
})
```

### object.success 回调函数

#### 参数

#### Object res

| 属性     | 类型     | 说明               |
|:-------|:-------|:-----------------|
| errMsg | String | setTabBarBadge: ok |
#### object.fail 回调函数

##### 参数

##### Object res

| 属性     | 类型         | 说明 |
|:-------|:-----------|:---|
| errMsg | String     | 错误信息 |
| errno  | Integer    | 错误码 |

#### 错误码列表

| 错误场景      | 错误码 | 安卓是否支持 | iOS是否支持 | 模拟器是否支持 | 开发建议                                                                                      |
|-----------|-----|--------|---------|---------|-------------------------------------------------------------------------------------------|
| 请求参数类型不合法 | 1   | 是      | 是       | 是       | 根据errorMsg排查接口调用参数中index、text类型是否合法                                                       |
| 请求参数数值不合法 | 2   | 是      | 是       | 是       | 根据errorMsg排查接口调用参数中参数数值是否合法，校验 index的值是否在当前小程序配置的tabbar index合理范围内，合理范围为0 到 配置的tabbar数量减1 |
| 请求参数缺少必填  | 3   | 是      | 是       | 是       | 根据errorMsg排查接口调用参数中是否含有index参数，是否含有text参数                                                 |
