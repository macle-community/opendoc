# ma.setStorageSync

同步将数据存储在本地缓存中指定的 key 中。会覆盖原来该 key 对应的内容。除非用户主动删除或因存储空间原因被系统清理，否则数据都一直可用。

> 单个 key 允许存储的最大数据长度，安卓为 10KB，iOS 为 1MB，所有数据存储上限为 10MB。

## 最低版本

24.9.0

## 参数说明

| 参数名 | 类型 | 默认值 | 必填 | 说明 |
|--------|------|--------|------|------|
| key | String | - | 是 | 本地缓存中指定的 key |
| data | Any | - | 是 | 需要存储的内容，只支持原生类型、Date、及能够通过 JSON.stringify 序列化的对象 |

## 使用示例

```javascript
try {
  ma.setStorageSync('userInfo', { name: '张三', age: 25 });
} catch (e) {
  // 错误处理
}
```

## 使用限制

- 最低支持版本：24.9.0
- key 必须为字符串类型

## Tips

1. 存储未作加密，涉及个人敏感数据请勿使用明文存储
