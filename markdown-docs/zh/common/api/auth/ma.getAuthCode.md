# ma.getAuthCode

获取用户授权码（登录凭证）。通过凭证获取用户登录态信息。

## 最低版本

24.3.0

## 参数说明

| 参数名 | 类型 | 默认值 | 必填 | 说明 |
|--------|------|--------|------|------|
| scopes | Array | - | 是 | 权限列表 |
| success | Function | - | 否 | 接口调用成功的回调函数 |
| fail | Function | - | 否 | 接口调用失败的回调函数 |
| complete | Function | - | 否 | 接口调用结束的回调函数（调用成功、失败都会执行） |

### scopes 列表

| 权限名称 | 权限描述 |
|----------|----------|
| AUTH_BASE | 授权获取用户ID |
| AUTH_USER | 授权获取用户ID及其他用户信息 |
| SEND_MESSAGE | 授权通过 SMS、PUSH 或 INBOX 向用户发送通知 |
| USER_NICKNAME | 授权获取用户昵称 |
| USER_NAME | 授权获取用户名 |
| USER_LOGIN_ID | 授权获取用户的登录ID |
| PLAINTEXT_USER_LOGIN_ID | 授权获取用户的明文登录ID |
| HASH_LOGIN_ID | 授权获取 hash 用户登录ID |
| USER_AVATAR | 授权获取用户头像 |
| USER_GENDER | 授权获取用户的性别 |
| USER_BIRTHDAY | 授权获取用户生日 |
| USER_NATIONALITY | 授权获取用户的国籍 |
| USER_CONTACTINFO | 授权获取用户的联系方式 |
| USER_ADDRESS | 授权获取用户的地址 |
| PLAINTEXT_MOBILE_PHONE | 授权获取用户的明文电话号码 |

### success 回调参数

| 属性 | 类型 | 说明 |
|------|------|------|
| errMsg | String | getAuthCode: ok |
| authCode | String | 用户登录凭证 |

### fail 回调参数

| 属性 | 类型 | 说明 |
|------|------|------|
| errMsg | String | 错误信息 |
| errno | String | 错误码 |

## 使用示例

```javascript
ma.getAuthCode({
  scopes: ['AUTH_BASE'],
  success(res) {
    console.log('授权码:', res.authCode);
  },
  fail(err) {
    console.log('获取失败:', err.errMsg);
  }
});
```

## 使用限制

- 最低支持版本：24.3.0
- scopes 为必填参数，必须为非空数组
- 使用此接口需要对接小程序 saas 平台
- 使用此接口需要宿主应用实现并注入获取授权码等相关功能
