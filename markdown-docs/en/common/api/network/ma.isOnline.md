# ma.isOnline

Determines whether the current device is connected to the internet.

## Minimum Version

23.12.0

## Return Value

boolean - true means online, false means offline

## Usage Example

```javascript
const isOnline = ma.isOnline();
console.log(isOnline ? 'online' : 'offline');
```

## Usage Restrictions

- Minimum supported version: 23.12.0
